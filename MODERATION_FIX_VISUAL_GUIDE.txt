Moderator wants to change from UPHELD to WITHDRAWN:

BEFORE: ❌ Cannot update - record already exists
┌─────────────────────────────────────────────────────────────────────────────┐
│ UPDATE marks SET ... WHERE learnerID = ? AND exercise = ?                  │
│ ❌ If record exists with same status → No change                           │
│ ❌ Cannot change from upheld → withdrawn                                   │
└─────────────────────────────────────────────────────────────────────────────┘

AFTER: ✅ Can update anytime
┌─────────────────────────────────────────────────────────────────────────────┐
│ INSERT INTO marks (...) VALUES (...)                                        │
│ ON DUPLICATE KEY UPDATE                                                     │
│   moderator_status = VALUES(moderator_status),                             │
│   approval_status = VALUES(approval_status), ...                           │
│                                                                             │
│ ✅ If record exists → UPDATE it                                            │
│ ✅ If record doesn't exist → INSERT it                                     │
│ ✅ Can change from upheld → withdrawn anytime                              │
└─────────────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────────────┐
│                            KEY IMPROVEMENTS                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1. PRECISE MATCHING
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ Before: learnerID + exercise                                             │
   │ After:  learnerID + exercise + type                                      │
   │ Result: ✅ No cross-contamination                                        │

2. UPDATE CAPABILITY
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ Before: Simple UPDATE (cannot change existing status)                   │
   │ After:  INSERT ... ON DUPLICATE KEY UPDATE (can update anytime)         │
   │ Result: ✅ Moderators can correct mistakes                               │
   └──────────────────────────────────────────────────────────────────────────┘

3. AUTO-DETECTION
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ If assessment_type not provided:                                         │
   │   - Check if exercise name contains "formative" → type = Formative       │
   │   - Check if exercise name contains "summative" → type = Summative       │
   │   - Otherwise → fallback to old logic (backward compatible)              │
   │ Result: ✅ Works with old and new data                                   │
   └──────────────────────────────────────────────────────────────────────────┘
