================================================================================
                          COMMON ISSUES & FIXES
================================================================================

ISSUE 1: Temp Tables Are Empty
-------------------------------
SYMPTOM: test_temp_tables_issue.php shows 0 learners in temp tables
CAUSE: Class filtering is too restrictive
FIX: Verify moderator has classes with learners who have POE

ISSUE 2: Unit Standards Count is 0
-----------------------------------
SYMPTOM: poe_count shows 0 for all learners
CAUSE: Unit standard extraction from exercise column is failing
FIX: Check exercise column format in database

ISSUE 3: Marking Status Always "Not Marked"
--------------------------------------------
SYMPTOM: All learners show "Not Marked" even if they have marks
CAUSE: No SUMMATIVE marks found, or marks query is wrong
FIX: Verify learners have marks with type = 'Summative'

ISSUE 4: Performance Always "Not Assessed"
-------------------------------------------
SYMPTOM: All learners show "Not Assessed"
CAUSE: avg_marks is NULL (no summative marks)
FIX: Verify learners have summative marks with marks_scored values

================================================================================
                            EXPECTED VALUES
================================================================================

For a learner with complete data:

Unit Standards Count:
- Range: 0-10 (10 total unit standards)
- Counts DISTINCT unit standards across poe, marks, logbook_marks

POE Completeness:
- Complete: 10/10 unit standards
- Partial: 1-9 unit standards
- Incomplete: 0 unit standards

Marking Status:
- Marked: Has at least one SUMMATIVE mark
- Not Marked: No SUMMATIVE marks

Performance Level:
- High: Average >= 70%
- Medium: Average >= 50% and < 70%
- Low: Average >= 0% and < 50%
- Not Assessed: No SUMMATIVE marks
