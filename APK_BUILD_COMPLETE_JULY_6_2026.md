## Troubleshooting

### Installation Issues

**"App not installed"**
- Check device storage (need 100MB+)
- Enable "Unknown Sources"
- Try clearing cache
- Restart device

**"Parse error"**
- APK may be corrupted
- Redownload file
- Verify file size matches (45.55 MB)
- Try different device

**"Permission denied"**
- Device may restrict installation
- Check device admin settings
- Try on different device
- Contact IT support

### Runtime Issues

**"App crashes on launch"**
- Clear app data
- Reinstall completely
- Update Android OS
- Check logs

**"Features not working"**
- Grant necessary permissions
- Ensure internet connection
- Update app
- Restart device
