│                          APPROVAL WORKFLOW                                   │
└─────────────────────────────────────────────────────────────────────────────┘

SCENARIO 1: Approval
─────────────────────
Moderator Action:
  ├─ Selects "Approved"
  ├─ Adds comment (optional): "Marks are appropriate"
  └─ Clicks Save

Database Update:
  ├─ approval_status = 'Approved'
  ├─ comment = 'Marks are appropriate'
  └─ updated_at = NOW()

Result:
  ├─ Marks remain: 85
  ├─ Assessor comments remain: "Good work"
  └─ Status visible to all: APPROVED ✓


SCENARIO 2: Disapproval
────────────────────────
Moderator Action:
  ├─ Selects "Disapproved"
  ├─ Adds comment (REQUIRED): "Needs more detail in section 3"
  └─ Clicks Save

Database Update:
  ├─ approval_status = 'Disapproved'
  ├─ comment = 'Needs more detail in section 3'
  └─ updated_at = NOW()

Result:
  ├─ Marks remain: 85 (NOT DELETED)
  ├─ Assessor comments remain: "Good work" (NOT DELETED)
  └─ Status visible to all: DISAPPROVED ✗

1. GET /mobile/get_pothole_checklist_marks.php
   ├─ Parameters: learner_id, assessor_id, assessment_date
   ├─ Returns: marks, comments, approval_status, comment
   └─ Used by: Moderator to view marks

2. POST /mobile/save_pothole_moderation.php
   ├─ Body: learner_id, assessment_date, approval_status, comment
   ├─ Updates: approval_status and comment columns
   └─ Used by: Moderator to save decision

  │
  ├─ IF approval_status IS NULL:
  │    └─> Show: [Moderate] (Orange) ◄─── Needs moderation
  │
  ├─ IF approval_status = 'Approved':
  │    └─> Show: [View (Approved)] (Green) ◄─── Already approved

ELSE (no marks):
  └─> Show: [No Marks] (Grey) ◄─── Assessor hasn't marked yet
