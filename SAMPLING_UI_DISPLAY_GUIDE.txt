WHAT EACH FIELD MEANS
═══════════════════════════════════════════════════════════════════════════════

POE Completeness:
  • Complete   - 3 or more POE documents across all tables
  • Partial    - 1-2 POE documents
  • Incomplete - 0 POE documents

Marking Status:
  • Marked     - Has assessment marks in marks or logbook_marks tables
  • Not Marked - No assessment marks yet

Performance Level:
  • High          - Average marks 70% or higher
  • Medium        - Average marks 50-69%
  • Low           - Average marks below 50%
  • Not Assessed  - No marks available

IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════════

1. PERSISTENT ASSIGNMENT
   Once you get your learners, they are saved to your account.
   Clicking "Get Learners with POE" again will show the SAME learners.
   This ensures consistency in moderation.

2. FAIR REPRESENTATION
   The 25% sampling ensures you get a fair mix of:
   • Different classes and sites
   • Learners with complete and incomplete POE
   • Both marked and unmarked learners
   • High, medium, and low performers

3. NO "UNKNOWN" VALUES
   All stratification data is calculated and stored.
   You should NOT see "Unknown" for any field.
   If you do, there's a data issue.

4. FAST LOADING
   First time: 2-5 seconds (calculates and stores)
   Subsequent times: <1 second (retrieves stored data)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If you see errors:
  ✗ "Unknown column 'class_id'"
    → Upload the fixed get_learners_with_poe_assigned.php file

  ✗ "504 Gateway Timeout"
    → The fix reduces query complexity and adds limits

  ✗ "Unknown system variable"
    → The fix removes MariaDB incompatible commands

  ✗ All fields show "Unknown"
    → Table columns missing - API will add them automatically

If you see "Unknown" values:
  • Check that learners have class assignments
  • Check that POE documents are uploaded
  • Check that marks are recorded

To reset your assignment:
  • Ask admin to run: TRUNCATE TABLE moderator_assignments;
  • Then click "Get Learners with POE" again for new random sample
