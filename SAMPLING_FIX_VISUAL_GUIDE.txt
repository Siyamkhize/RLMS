PROBLEM: 504 Timeout + "Unknown" Values
═══════════════════════════════════════

BEFORE (Slow & Broken):
┌─────────────────────────────────────────────────────────────────────────────┐
│ Moderator requests sampling                                                 │
│         ↓                                                                    │
│ Check if assignment exists                                                  │
│         ↓                                                                    │
│ YES → Retrieve existing assignment                                          │
│         ↓                                                                    │
│ ❌ RECALCULATE stratification data:                                         │
│    - JOIN learnerdetails + poe + marks + class                             │
│    - COUNT POE documents                                                    │
│    - AVG marks for performance                                              │
│    - Complex aggregations                                                   │
│         ↓                                                                    │
│ ⏱️  30-60+ seconds... TIMEOUT! 504 Error                                    │
│         ↓                                                                    │
│ ❌ Return "Unknown" values or error                                         │
└─────────────────────────────────────────────────────────────────────────────┘


SOLUTION: Store Metadata Once
═══════════════════════════════

AFTER (Fast & Working):
┌─────────────────────────────────────────────────────────────────────────────┐
│ FIRST TIME (New Assignment):                                                │
│ ─────────────────────────────                                               │
│ Moderator requests sampling                                                 │
│         ↓                                                                    │
│ Check if assignment exists → NO                                             │
│         ↓                                                                    │
│ Calculate stratification for available learners                             │
│    - POE completeness (Complete/Partial/Incomplete)                         │
│    - Marking status (Marked/Not Marked)                                     │
│    - Performance level (High/Medium/Low/Not Assessed)                       │
│         ↓                                                                    │
│ Perform stratified random sampling (25% from each stratum)                  │
│         ↓                                                                    │
│ 💾 STORE stratification metadata in database:                               │
│    INSERT INTO moderator_assignments (                                      │
│        moderator_id, learner_id, class_id, site_id,                        │
│        poe_completeness, marking_status, performance_level, poe_count      │
│    )                                                                         │
│         ↓                                                                    │
│ ✅ Return learners with full stratification data                            │
│ ⏱️  2-5 seconds (acceptable)                                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ SUBSEQUENT TIMES (Existing Assignment):                                     │
│ ────────────────────────────────────────                                    │
│ Moderator requests sampling                                                 │
│         ↓                                                                    │
│ Check if assignment exists → YES                                            │
│         ↓                                                                    │
│ 📖 RETRIEVE stored stratification metadata:                                 │
│    SELECT l.*, ma.poe_completeness, ma.marking_status,                     │
│           ma.performance_level, ma.poe_count                                │
│    FROM moderator_assignments ma                                            │
│    JOIN learnerdetails l ON ma.learner_id = l.LearnerID                   │
│    WHERE ma.moderator_id = ?                                                │
│         ↓                                                                    │
│ ✅ Return learners with full stratification data                            │
│ ⏱️  < 1 second (FAST!)                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
