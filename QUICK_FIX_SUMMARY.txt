BEFORE (Wrong):
  Gets ALL manual registers in date range
  → Includes documents from other classes ❌

AFTER (Correct):
  Gets only manual registers for THIS learner
  → Only documents for selected learners ✅

SQL Query Now:
  SELECT * FROM manual_clocking 
  WHERE LearnerID = {specific_learner}
  AND clock_date BETWEEN {start} AND {end}
