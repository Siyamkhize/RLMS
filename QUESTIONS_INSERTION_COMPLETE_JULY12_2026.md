## 📋 DATABASE QUERIES

### View All Questions by Trade

```sql
SELECT 
  p.trade_ofo_code,
  p.paper_type,
  p.paper_number,
  p.paper_title,
  COUNT(q.id) as questions,
  SUM(q.marks) as total_marks
FROM arpl_papers p
LEFT JOIN arpl_questions q ON p.id = q.paper_id
WHERE p.trade_ofo_code IN ('641201', '671101')
GROUP BY p.id
ORDER BY p.trade_ofo_code, p.paper_type DESC, p.paper_number;
```

### View Questions for Specific Paper

```sql
SELECT 
  question_number,
  question_text,
  question_type,
  marks,
  difficulty_level,
  learning_outcome
FROM arpl_questions
WHERE paper_id = 11
ORDER BY question_number;
```

### Total Marks by Paper

```sql
SELECT 
  p.paper_title,
  COUNT(q.id) as question_count,
  SUM(q.marks) as total_marks
FROM arpl_papers p
LEFT JOIN arpl_questions q ON p.id = q.paper_id
GROUP BY p.id
ORDER BY p.id;
```
