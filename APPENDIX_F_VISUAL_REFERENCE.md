- Columns: 4
- Rows: 8 (no header, header is above table)
- Column Widths: 50, 250, 80, 80 pixels

### Practical Section Table
- Columns: 4
- Rows: 13 (no header, header is above table)
- Column Widths: 50, 250, 80, 80 pixels
- Signature row below: Assessor signature + date

### Workplace Observation Table
- Columns: 5
- Rows: 13 with electrical activities
- Column Widths: 50, 220, 120, 120, 120 pixels
- Activities: Pre-filled electrical task names
- Input fields: For Technical Knowledge, Interpretation, Team Work

## EDITABLE FIELDS

### Knowledge Section
- **Questions Column:** Editable text field (user enters question)
- **Candidate Score Column:** Editable text field (user enters score)
- **Percentage Column:** Editable text field (user enters percentage)

### Practical Section
- **Tasks Column:** Editable text field (user enters task name)
- **Score Column:** Editable text field (user enters score)
- **Percentage Column:** Editable text field (user enters percentage)
- **Assessor Signature:** Editable text field for signature
- **Assessor Date:** Editable text field for date

### Workplace Observation
- **Tasks Observed:** Pre-filled (non-editable)
- **Technical Knowledge:** Editable text field (user enters rating/comment)
- **Interpretation:** Editable text field (user enters rating/comment)
- **Team Work:** Editable text field (user enters rating/comment)

### Sign-Off Sections
- **Assessor Signature & Date:** Editable
- **Candidate Signature & Date:** Editable
- **Witness Signature & Date:** Editable

## RESPONSIVE BEHAVIOR

### Horizontal Scrolling
- Tables wider than screen width will scroll horizontally
- SingleChildScrollView wraps each table section
- Headers remain visible during scroll

### Card Layout
- Each section is wrapped in a Card widget
- Provides elevation/shadow effect
- Clear visual separation between sections

### Spacing
- Vertical spacing: 24px between sections
- Horizontal padding: 16px
- Vertical padding in cards: 16px
