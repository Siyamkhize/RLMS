QUICK FIX: EXERCISE COLUMN JOIN
========================================

PROBLEM:
- Marking Status always "Not Marked"
- Performance Level always "Not Assessed"
- Unit Standards Count always 0

ROOT CAUSE:
- marks.type column is wrong (all set to "Formative")
- Need to join with assessments table to get correct type

SOLUTION:
Join marks with assessments using exercise column (text field)

  FROM marks m
  INNER JOIN assessments a ON m.exercise = a.exercise
  WHERE a.assessment_type = 'Summative'
