TECHNICAL FLOW:
---------------

FLUTTER APP:
┌─────────────────────────────────────────────────────────┐
│ 1. User clicks "Scan" button                            │
│    ↓                                                     │
│ 2. Open PoeDocumentScanner widget                       │
│    ↓                                                     │
│ 3. Launch CunningDocumentScanner                        │
│    - User scans pages (up to 195)                       │
│    - Returns list of image paths                        │
│    ↓                                                     │
│ 4. Convert images to PDF                                │
│    - Create PDF document                                │
│    - Add each image as page                             │
│    - Save to device storage                             │
│    ↓                                                     │
│ 5. Check PDF file size                                  │
│    ↓                                                     │
│    ├─ IF < 50MB:                                        │
│    │  └─ Call _uploadDirect()                           │
│    │     - Create MultipartRequest                      │
│    │     - Add file and metadata                        │
│    │     - Send to server                               │
│    │                                                     │
│    └─ IF > 50MB:                                        │
│       └─ Call _uploadChunked()                          │
│          - Read file as bytes                           │
│          - Split into 5MB chunks                        │
│          - Upload each chunk sequentially               │
│          - Update progress bar                          │
│    ↓                                                     │
│ 6. Show success message                                 │
│ 7. Return to previous page                              │
└─────────────────────────────────────────────────────────┘


SERVER (PHP):
┌─────────────────────────────────────────────────────────┐
│ upload_poe_document.php                                 │
│                                                          │
│ 1. Receive POST request                                 │
│    ↓                                                     │
│ 2. Check if chunked upload                              │
│    - Look for chunk_index parameter                     │
│    ↓                                                     │
│    ├─ IF NOT CHUNKED (Direct Upload):                  │
│    │  1. Validate file upload                           │
│    │  2. Check file size < 200MB                        │
│    │  3. Validate MIME type                             │
│    │  4. Generate unique filename                       │
│    │  5. Move file to uploads/poe_documents/            │
│    │  6. Insert record to database                      │
│    │  7. Return success JSON                            │
│    │                                                     │
│    └─ IF CHUNKED:                                       │
│       1. Save chunk to temp directory                   │
│       2. Check if last chunk                            │
│          ↓                                               │
│          ├─ IF NOT LAST:                                │
│          │  └─ Return "chunk received" JSON             │
│          │                                               │
│          └─ IF LAST CHUNK:                              │
│             1. Open final file for writing              │
│             2. Loop through all chunks                  │
│             3. Read each chunk                          │
│             4. Write to final file                      │
│             5. Delete chunk file                        │
│             6. Close final file                         │
│             7. Insert record to database                │
│             8. Return success JSON                      │
│    ↓                                                     │
│ 3. Client receives response                             │
└─────────────────────────────────────────────────────────┘

ERROR HANDLING:
---------------

Scenario 1: Network Disconnects During Upload
  → Flutter: Shows error message
  → User: Can retry upload
  → Server: Orphaned chunks cleaned up later

Scenario 2: File Too Large (> 200MB)
  → Server: Returns error before processing
  → Flutter: Shows "File too large" message
  → User: Must reduce page count or quality

Scenario 3: Upload Directory Not Writable
  → Server: Returns permission error
  → Admin: Must run: chmod 777 uploads/poe_documents

Scenario 4: Database Insert Fails
  → Server: Deletes uploaded file
  → Returns error to Flutter
  → User: Can retry upload

SECURITY CONSIDERATIONS:
------------------------

1. File Type Validation:
   - Check MIME type on server
   - Only allow PDF, JPEG, PNG

2. File Size Limits:
   - Maximum 200MB per document
   - Prevents server overload

3. Unique Filenames:
   - Prevents overwriting existing files
   - Format: POE_{learnerID}_{timestamp}_{uniqueID}.pdf

4. Directory Permissions:
   - Upload directory outside web root (recommended)
   - Or use .htaccess to prevent direct access

5. Database Sanitization:
   - All inputs escaped with real_escape_string
   - Prevents SQL injection
