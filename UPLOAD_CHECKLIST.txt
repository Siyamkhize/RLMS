🔧 POST-UPLOAD STEPS
═══════════════════════════════════════════════════════════════

STEP 1: Set File Permissions
□ chmod 755 bulk_export_chunked.php
□ chmod 755 bulk_download_chunked.js
□ chmod 755 test_chunked_export.php

STEP 2: Create Temp Directory
□ mkdir -p temp_reports
□ chmod 777 temp_reports

STEP 3: Verify Dependencies
□ PHP mysqli extension enabled
□ PHP zip extension enabled
□ PHP gd or imagick extension enabled
□ Composer package mpdf/mpdf installed

STEP 4: Test System
□ Open test_chunked_export.php in browser
□ Run Test 4 (API Endpoint Test)
□ Verify ✅ green checkmark appears

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

IF BUTTON DOESN'T WORK:
□ Clear browser cache (Ctrl+F5)
□ Check browser console (F12) for errors
□ Verify bulk_download_chunked.js is loaded

IF "SESSION NOT FOUND" ERROR:
□ Check temp_reports/ directory exists
□ Verify permissions: chmod 777 temp_reports

IF PROGRESS STUCK AT 0%:
□ Open browser console (F12)
□ Check for JavaScript errors
□ Verify API endpoint is accessible

IF ZIP FILE EMPTY:
□ Check PHP error logs
□ Verify mPDF is installed
□ Check PHP memory limit (512M recommended)
