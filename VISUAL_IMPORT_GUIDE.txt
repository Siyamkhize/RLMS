PROBLEM: "MySQL server has gone away"
SOLUTION: Edit MySQL config
┌─────────────────────────────────────────────────────────────┐
│  1. Open: C:\xampp\mysql\bin\my.ini                        │
│  2. Find: max_allowed_packet = 1M                           │
│  3. Change to: max_allowed_packet = 64M                     │
│  4. Save file                                               │
│  5. Restart MySQL in XAMPP                                  │
│  6. Try import again                                        │
└─────────────────────────────────────────────────────────────┘

PROBLEM: MySQL won't start in XAMPP
SOLUTION: Check port conflict
┌─────────────────────────────────────────────────────────────┐
│  1. Click "Config" next to MySQL in XAMPP                   │
│  2. Select "my.ini"                                         │
│  3. Find: port=3306                                         │
│  4. Change to: port=3307 (if 3306 is in use)               │
│  5. Save and restart MySQL                                  │
└─────────────────────────────────────────────────────────────┘
