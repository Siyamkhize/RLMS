================================================================================
METHOD 1: PowerShell (Recommended - With Automatic Backup)
================================================================================

Run this in PowerShell (as Administrator):

$ts = Get-Date -Format "yyyyMMdd_HHmmss"
if (Test-Path "C:\xampp\htdocs\web") { 
    Write-Host "Backing up existing web folder..." -ForegroundColor Yellow
    Rename-Item "C:\xampp\htdocs\web" "web_backup_$ts" -Force
}
Copy-Item -Path "C:\projects\rlmss\web\*" -Destination "C:\xampp\htdocs\web" -Recurse -Force
if (Test-Path "C:\xampp\htdocs\web\index.php") {
    Write-Host "✓ SUCCESS: Files deployed to C:\xampp\htdocs\web\" -ForegroundColor Green
    Write-Host "✓ Access URL: http://localhost:8080/web/index.php" -ForegroundColor Green
} else {
    Write-Host "✗ ERROR: Deployment failed" -ForegroundColor Red
}

================================================================================
METHOD 2: Command Prompt (Simple)
================================================================================

Run this in Command Prompt (as Administrator):

xcopy "C:\projects\rlmss\web\*" "C:\xampp\htdocs\web\" /E /I /Y

Then verify:
dir C:\xampp\htdocs\web\index.php

================================================================================
METHOD 3: Command Prompt (With Backup)
================================================================================

Run this in Command Prompt (as Administrator):

for /f "tokens=2-4 delims=/ " %%a in ('date /t') do (set mydate=%%c%%a%%b)
for /f "tokens=1-2 delims=/:" %%a in ('time /t') do (set mytime=%%a%%b)
if exist "C:\xampp\htdocs\web" ren "C:\xampp\htdocs\web" "web_backup_%mydate%_%mytime%"
xcopy "C:\projects\rlmss\web\*" "C:\xampp\htdocs\web\" /E /I /Y
dir C:\xampp\htdocs\web\index.php

TROUBLESHOOTING

If deployment fails, check:

1. Source files exist:
   dir C:\projects\rlmss\web\

2. Apache document root accessible:
   dir C:\xampp\htdocs\

3. Try manual copy (File Explorer):
   - Open: C:\projects\rlmss\web\
   - Select All (Ctrl+A)
   - Copy (Ctrl+C)
   - Navigate to: C:\xampp\htdocs\
   - Paste (Ctrl+V)

4. Clear browser cache:
   Ctrl+F5 on the webpage

5. Restart Apache:
   XAMPP Control Panel → Stop Apache → Wait → Start Apache
