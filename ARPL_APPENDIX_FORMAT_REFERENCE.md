## Key Format Elements Used Throughout

### Checkbox Symbol
`☐` Empty checkbox for selections

### Table Conventions
- ✅ Prefilled fields have light gray background
- ✅ Borders for signature/date areas for handwritten entries
- ✅ Two-column layouts for address and employment sections
- ✅ Grid layouts for ratings (1-5 scale)

### Typography
- ✅ Bold headers and section titles
- ✅ 10-12pt font for body text
- ✅ Smaller headers for sub-sections
- ✅ Professional formatting throughout

### Page Layout
- ✅ A4 size (297mm height)
- ✅ 40px margins on all sides
- ✅ Proper page breaks between sections
- ✅ Professional gradient cover page

## Implementation Notes

All these formats are automatically generated by the PDF generation engine in `web/api/generate_arpl_pdf.php`. The system automatically detects the trade from the OFO code and uses the appropriate database tables for any trade-specific data.

**Trade Auto-Detection:**
- Electrician (671101) → Uses `arplappxb_electrician_*` tables
- Bricklaying (641201) → Uses `arplappxb_bricklaying_*` tables
- Plumbing (642601) → Uses `arplappxb_plumbing_*` tables

No manual configuration is needed.
