================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Cannot find file" or "404 Not Found"
------------------------------------------
Solution:
1. Check files are in correct location:
   - Open File Explorer
   - Go to C:\xampp\htdocs\web\
   - Verify index.php exists there (NOT in rlmss folder)
2. Restart Apache:
   - XAMPP Control Panel → Stop Apache
   - Wait 2 seconds
   - Click Start Apache
   - Try accessing URL again

Problem: "Database connection failed"
------------------------------------------
Solution:
1. Verify MySQL is running:
   - XAMPP Control Panel → Check MySQL shows "Running"
   - If not, click Start MySQL
2. Check database configuration:
   - The code uses database: rlmsrlmsco_ezxcmacd_rlms
   - This should already be set up from your mobile app
   - If you get connection error, your database may not exist

Problem: "No trades showing" or blank page
------------------------------------------
Solution:
1. Check browser console for errors:
   - Press F12 on keyboard
   - Click "Console" tab
   - Look for red error messages
2. Check browser cache:
   - Press Ctrl+F5 to hard refresh (clears cache)
3. Try different browser (Chrome, Firefox, Edge)

Problem: Classes don't load when clicking trade
------------------------------------------
Solution:
1. Check API is working:
   - Open new tab
   - Go to: http://localhost:8080/web/api/get_arpl_trades.php
   - You should see JSON response with 3 trades
   - If not, database connection is broken
2. Check database tables exist:
   - Make sure your RLMS database has "class" table
   - If missing, data setup scripts may need to run

Problem: Excel says "http://localhost:8080/rlmss/web/index.php does not exist"
------------------------------------------
IMPORTANT: You must use the CORRECT URL:
   ❌ WRONG: http://localhost:8080/rlmss/web/index.php
   ❌ WRONG: http://localhost:8080/projects/rlmss/web/index.php
   ✓ CORRECT: http://localhost:8080/web/index.php

Explanation:
- Apache document root is C:\xampp\htdocs\
- So http://localhost:8080/ maps to C:\xampp\htdocs\
- Your files are in C:\xampp\htdocs\web\
- Therefore the URL is http://localhost:8080/web/
