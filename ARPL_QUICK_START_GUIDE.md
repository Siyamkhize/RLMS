# ARPL Portfolio Generator - Quick Start Guide

## 📋 What is ARPL?

ARPL stands for **Articulated Recognition of Prior Learning**. It's a system for assessing and recognizing skills and knowledge gained through work experience.

This web module allows you to:
- Generate professional ARPL portfolios
- Organize assessment evidence
- Create 24-page PDF documents
- Track learner progress

---

## 🚀 Quick Start (3 Steps)

### Step 1: Go to ARPL Portal
```
URL: http://localhost/web/web/web/index.php
```

### Step 2: Follow the Workflow
```
1. Select a Trade (Electrician, Bricklaying, Plumbing, or Welding)
2. Select a Class for that trade
3. See list of learners in the class
```

### Step 3: Generate Portfolio
```
1. Click "Generate ARPL ▶" for any learner
2. Click OK to confirm
3. Wait for portfolio to generate (< 2 seconds)
4. 🖨️ Print or ⬇️ Download the portfolio
```

---

## 📚 Portfolio Structure (24 Pages)

Your ARPL portfolio includes:

### Cover & Information (Pages 1-3)
- Professional cover page
- Portfolio checklist
- Learner personal information

### Supporting Documents (Pages 4-6)
- Certified ID copy
- Curriculum Vitae (CV)
- Qualifications and certificates
- Service letters

### Assessment Evidence (Pages 7-22)
- **Appendices A-I** (Pages 7-15) - Assessment components
- **Theory Assessment** (Pages 16-17) - Theory papers
- **Practical Assessment** (Pages 18-19) - Practical work
- **Workplace Experience** (Pages 20-22) - Workplace evidence

### Conclusion (Pages 23-24)
- Assessment summary
- Assessor decision area
- Signature and date fields

## 💾 What You Can Do With the Portfolio

### 🖨️ Print to PDF
1. Click "Print PDF" button
2. Select your printer or "Save as PDF"
3. PDF will be saved to your computer

### ⬇️ Download as HTML
1. Click "Download HTML" button
2. File will be downloaded to your Downloads folder
3. Open in any web browser to view

### 📧 Share Portfolio
1. Download the HTML file
2. Email to assessor or learner
3. Can be viewed in any browser without software

### 📝 Add Notes
1. Open in browser
2. Use browser print dialog to add notes (Print → More Settings → Margins)
3. Print with your annotations

## ⚠️ Troubleshooting

### Issue: Portfolio didn't generate
**Solution:** 
1. Check console (F12) for errors
2. Try again - may be network issue
3. Check if learner ID is correct

### Issue: Portfolio is blank
**Solution:**
1. Try refreshing the page
2. Check browser console for errors
3. Try different browser (Chrome, Firefox, Edge)

### Issue: Can't print to PDF
**Solution:**
1. Use "Download HTML" instead
2. Open downloaded file in browser
3. Use browser's print feature (Ctrl+P)

### Issue: Downloaded file won't open
**Solution:**
1. Try opening with different browser
2. File should be an HTML file
3. Can also open with text editor
