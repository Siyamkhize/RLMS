TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

If Activities Don't Show:
  1. Verify database tables exist: SELECT COUNT(*) FROM arplappxe_*;
  2. Check API response includes appendixE key
  3. Test API directly with curl
  4. Check Flutter logs: flutter logs | grep appendixE

If API Returns Error:
  1. Check server is running: ping 192.168.0.57
  2. Verify tables exist with data
  3. Check MySQL error log
  4. Test prepared statement queries

If Ratings Don't Save:
  1. Verify save_arpl_appendix_f_assessment.php exists
  2. Check rating tables exist
  3. Verify learnerID in requests
  4. Check server logs for SQL errors
