DATABASE TABLES USED
====================

sick_note
─────────
• note_id
• learner_id
• document_path ← File location
• date_from
• date_to
• status (approved/pending/rejected)

manual_clocking
───────────────
• manual_id
• LearnerID
• clock_date
• fdp_document ← File location
• status

learnerdetails
──────────────
• LearnerID
• Name
• Surname
• IDNumber
• activity_statu (filter for active learners)


FILE PATH CHECKING LOGIC
=========================

For Sick Notes:
1. Original path from database
2. mobile/sicknotes/[filename]
3. /public_html/mobile/sicknotes/[filename]
4. ../mobile/sicknotes/[filename]
5. __DIR__/mobile/sicknotes/[filename]

For Manual Registers:
1. Original path from database
2. uploads/[filename]
3. /public_html/uploads/[filename]
4. ../uploads/[filename]
5. __DIR__/uploads/[filename]


ERROR HANDLING
==============

✓ Learner not found → Skip, log error
✓ Document file missing → Skip, continue with others
✓ No documents for learner → Create NO_DOCUMENTS_FOUND.txt
✓ ZIP creation fails → Return error JSON
✓ Directory creation fails → Return error JSON
✓ Database query fails → Return error JSON

All errors are:
• Logged to PHP error log
• Included in DOWNLOAD_SUMMARY.txt
• Returned in JSON response


PERFORMANCE OPTIMIZATION
========================

• Direct file operations (no external tools)
• Efficient database queries (prepared statements)
• Single ZIP creation (no multiple archives)
• Temporary directory cleanup
• Progress feedback to user


SECURITY MEASURES
=================

✓ Validate learner IDs (integer only)
✓ Sanitize file names (remove special chars)
✓ Check file existence before copying
✓ Only active learners (activity_statu filter)
✓ Date range validation
✓ Temporary file cleanup
✓ Error logging for audit trail
