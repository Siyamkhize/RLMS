  QUERY COMPARISON
═══════════════════════════════════════════════════════════════════════════════

SIMPLE COUNT QUERY (NEW):
─────────────────────────────────────────────────────────────────────────────
  SELECT COUNT(DISTINCT learnerID) as total FROM poe
  
  ✅ Fast: ~5-10ms
  ✅ Simple: No joins, no filters
  ✅ Accurate: Returns 1571
  ✅ No timeout risk


COMPLEX QUERY (Existing - Still Used):
─────────────────────────────────────────────────────────────────────────────
  SELECT COUNT(DISTINCT p.learnerID) as total 
  FROM poe p
  INNER JOIN learnerdetails l ON p.learnerID = l.LearnerID
  WHERE p.filePath IS NOT NULL AND p.filePath != ''
  AND l.classID IN (69,93,67,68,91,81,30,97,46,86,47)
  
  ⚠️  Slower: Multiple joins
  ⚠️  Complex: Class filtering
  ✅ Accurate: Returns 273 (moderator's classes)
  ⚠️  Can timeout on large datasets

  THREE RETURN SCENARIOS
═══════════════════════════════════════════════════════════════════════════════

SCENARIO 1: Existing Assignments
─────────────────────────────────────────────────────────────────────────────
  Moderator already has assignments (273 learners)
  
  Response:
  {
    "total_learners_with_poe_global": 1571,  ← All learners in database
    "total_learners_with_poe": 273,          ← In moderator's classes
    "selected_count": 273,                    ← Already assigned
    "is_existing_assignment": true
  }


SCENARIO 2: No Learners Available
─────────────────────────────────────────────────────────────────────────────
  No learners with POE in moderator's classes
  
  Response:
  {
    "total_learners_with_poe_global": 1571,  ← All learners in database
    "total_learners_with_poe": 0,            ← None in moderator's classes
    "selected_count": 0,                      ← None assigned
    "is_existing_assignment": false
  }


SCENARIO 3: New Assignments (Sampling)
─────────────────────────────────────────────────────────────────────────────
  First time assignment - performs stratified sampling
  
  Response:
  {
    "total_learners_with_poe_global": 1571,  ← All learners in database
    "total_learners_with_poe": 1000,         ← Available in moderator's classes
    "selected_count": 250,                    ← 25% sampled and assigned
    "is_existing_assignment": false,
    "sampling_rate": "25%"
  }


═══════════════════════════════════════════════════════════════════════════════
  FIELD MEANINGS
═══════════════════════════════════════════════════════════════════════════════

  total_learners_with_poe_global (NEW)
  ─────────────────────────────────────────────────────────────────────────
  • Total distinct learners with POE in ENTIRE database
  • Uses simple query: SELECT COUNT(DISTINCT learnerID) FROM poe
  • No class filtering, no joins
  • Value: 1571
  • Purpose: Show "big picture" total
  
  
  total_learners_with_poe (Existing)
  ─────────────────────────────────────────────────────────────────────────
  • Total learners with POE in MODERATOR'S ALLOCATED CLASSES
  • Uses complex query with class filtering
  • Value: 273 (for moderator 77)
  • Purpose: Show available pool for this moderator
  
  
  selected_count (Existing)
  ─────────────────────────────────────────────────────────────────────────
  • Number of learners ASSIGNED to this moderator
  • For existing assignments: same as total_learners_with_poe
  • For new assignments: 25% sample from total_learners_with_poe
  • Value: 273 (for moderator 77)
  • Purpose: Show actual assignment size
