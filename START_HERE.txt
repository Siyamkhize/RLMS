🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Button doesn't work
  FIX: Clear browser cache (Ctrl+F5)

PROBLEM: "Session not found" error
  FIX: chmod 777 temp_reports

PROBLEM: Progress stuck at 0%
  FIX: Press F12, check console for errors

PROBLEM: ZIP file empty
  FIX: Check PHP error logs, verify mPDF installed

PROBLEM: Database connection error
  FIX: Verify connection.php is correct
