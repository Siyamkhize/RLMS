OPTION 1: WINDOWS EXPLORER (EASIEST)
═════════════════════════════════════

Step 1: Open File Explorer
        [Start] → [File Explorer]

Step 2: Navigate to Source
        C:\projects\rlmss\web\
        
        You should see:
        ├─ index.php
        ├─ classes.php
        ├─ api/ folder
        ├─ assets/ folder
        └─ ... (other files)

Step 3: Select All Files
        [Ctrl + A]
        
Step 4: Copy
        [Ctrl + C]
        
Step 5: Navigate to Destination
        C:\xampp\htdocs\
        
Step 6: Paste
        [Ctrl + V]
        
        If asked "Replace files?" → Click YES
        
Step 7: Wait for copy to complete
        
Step 8: Done ✓


OPTION 2: POWERSHELL (FASTEST - RECOMMENDED)
═════════════════════════════════════════════

Step 1: Open PowerShell as Administrator
        [Right-click Start] → [Windows PowerShell (Admin)]
        
Step 2: Copy entire command block below:

        $ts = Get-Date -Format "yyyyMMdd_HHmmss"
        if (Test-Path "C:\xampp\htdocs\web") { 
            Write-Host "Backing up existing files..." -ForegroundColor Yellow
            Rename-Item "C:\xampp\htdocs\web" "web_backup_$ts" -Force
        }
        Copy-Item -Path "C:\projects\rlmss\web\*" -Destination "C:\xampp\htdocs\web" -Recurse -Force
        if (Test-Path "C:\xampp\htdocs\web\index.php") {
            Write-Host "✓ SUCCESS: Files deployed" -ForegroundColor Green
            Write-Host "✓ URL: http://localhost:8080/web/index.php" -ForegroundColor Green
        } else {
            Write-Host "✗ ERROR: Deployment failed" -ForegroundColor Red
        }
        
Step 3: Right-click in PowerShell → [Paste]
        
Step 4: Press [Enter]
        
Step 5: Wait for success message
        
Step 6: Done ✓

================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: Still getting 404 error
─────────────────────────────────

CHECK:
□ Apache is running
  - XAMPP Control Panel should show Apache as "Running"
  - If not: Click [Start] button next to Apache
  
□ Files actually copied to C:\xampp\htdocs\web\
  - Open File Explorer
  - Navigate to C:\xampp\htdocs\web\
  - Should see index.php file there
  
□ Try restarting Apache
  - XAMPP Control Panel
  - Click [Stop] Apache
  - Wait 2 seconds
  - Click [Start] Apache
  
□ Clear browser cache
  - In browser: Ctrl + F5
  - (Hard refresh - clears cache)


PROBLEM: Can see trade cards but classes won't load
────────────────────────────────────────────────────

CHECK:
□ MySQL is running
  - XAMPP Control Panel should show MySQL as "Running"
  - If not: Click [Start] button
  
□ Database exists
  - Database name: rlmsrlmsco_ezxcmacd_rlms
  - Should be from your RLMS mobile app
  
□ Check browser console for errors
  - Press F12 on keyboard
  - Click "Console" tab
  - Look for red error messages


PROBLEM: Getting "Database Connection Failed"
──────────────────────────────────────────────

CHECK:
□ MySQL is running (check XAMPP)
□ Database name is correct in connection.php
□ Database has "class" table
□ class table has data with trades:
   - ofoNumber 671101 (Electrician)
   - ofoNumber 641201 (Bricklaying)
   - ofoNumber 671102 (Plumbing)


PROBLEM: Files won't copy / Permission denied
──────────────────────────────────────────────

SOLUTION:
□ Run as Administrator
  - Right-click Command Prompt/PowerShell
  - Select "Run as Administrator"
  
□ If C:\xampp\htdocs\web\ locked:
  - Restart Apache (Stop → Wait → Start)
  - Then try copying again
