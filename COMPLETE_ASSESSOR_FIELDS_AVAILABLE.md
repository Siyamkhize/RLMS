## Database JOIN

The assessor data is retrieved using:
```sql
LEFT JOIN facilitator f ON f.classID = c.classID AND f.role = 'Assessor'
```

This means:
- The system looks for a facilitator record where `classID` matches the learner's class
- AND where `role = 'Assessor'` (case-sensitive!)
- Uses LEFT JOIN so documents generate even if no assessor is assigned
- If no assessor found, all fields show "N/A"
